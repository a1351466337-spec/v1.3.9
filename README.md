# 渴瘾 Vorax Solver · Android 移植研究

> **状态：Android 16 ARM64 实机原生加载、求解与取消已获首次验证；真实游戏识别仍待开发（2026-11-13）**  
> 本仓库是独立的公开上游来源与进度记录仓库，**不是火炬AI助手 Android APP 的源码仓库，也不提供 APK**。仓库名称 `v1.3.9` 不代表当前 Android 软件版本。

## 项目目标

研究将 Torchlight: Infinite「渴瘾 / Surgical Preparation」玩法的开源 Rust 求解器移植至 Android ARM64。工具只读取游戏画面与获准读取的游戏日志，并向玩家提供建议；**不自动点击、按键或操作游戏**。

## 首次 Android 16 实机报告（2026-11-13）

用户提供的独立测试 APP 原始运行日志证明：设备运行时为 Android API 36 / ARM64 / .NET 10.0.15；基础测试通过原生加载、真正的只读求解建议、非法输入拒绝和预取消。**合成局面**的运行耗时如下：

| futures / 线程 | 3 次求解 (ms) | 平均 (ms) | 成功 |
| --- | --- | ---: | --- |
| 256 / 2 | 137、143、93 | 124.3 | 3/3 |
| 512 / 4 | 258、324、203 | 261.7 | 3/3 |
| 1024 / 6 | 330、207、223 | 253.3 | 3/3 |

另一次运行中的深度求解在收到取消请求后返回 `CANCELLED`；该次测试总耗时 649 ms，日志不足以计算请求至完成的精确取消延迟。不同 futures 产生不同建议，不代表已经确认推荐质量或算法错误。

**重要边界：** 测试使用固定合成单卡牌、单已占培养槽，尚无真实战局多卡牌求解、手机视觉/OCR、S13/KYZ 日志解析、连续长测、温度/内存/耗电或最终 APP 实机验收数据。没有发布正式 APK，不公开私有代码、日志或用户特定资料。
